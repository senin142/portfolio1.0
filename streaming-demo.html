Personal project · practice build

Video player access control: geography + time-window blocking

Two patterns from broadcast video work, rebuilt as an original demo: a live-stream player that enforces a simulated region block plus a recurring scheduled break, and a VOD player with a playlist. Both use Video.js, an open-source HTML5 player.

Not employer work — an original, clean-room practice build. Streams are free, publicly available demo sources (see credits below each player), not real broadcast infrastructure.

01 · Live Stream

Region + time-window blocking

This demo assumes the viewer is in India, so the stream is geo-blocked by default. Separately, it also blocks automatically during the last 5 minutes of every hour (a scheduled-break window) — a common pattern for ad-insertion or rights windows around the top of the hour. Either condition shows an overlay with an "Unblock" button so you can see the content anyway.
